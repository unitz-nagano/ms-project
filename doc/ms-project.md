# MS Project 機能要件一覧

## 1. 基本計画・タスク管理（Core Features）

### 1-1. WBS（作業分解構成案）と階層構造管理

プロジェクトの作業を構造化し、視覚的に整理・集計するための機能です。

#### 要件一覧

- **階層化（インデント機能）**
  - タスクに親子の階層関係（レベル1, レベル2...）を設定可能とする。
- **親タスク（サマリータスク）の自動集計**
  - 親タスクの日付・期間・進捗率は、傘下にある子タスクのデータから自動算出する（直接編集は不可）。
  - 開始日：最小の子タスク開始日 / 終了日：最大の子タスク終了日。
- **マイルストーン**
  - 期間（Duration）を「0日」として設定されたタスクを重要ポイントとして扱う。
  - 画面上では通常のバーではなく菱形アイコン等で描画する。

### 1-2. スケジュール計算と期間設定

作業時間および営業日を考慮した日付計算ロジックです。

#### 要件一覧

- **期間（Duration）と工数（Work）の管理**
  - 期間：タスクの開始から終了までの所要日数（例: 3日）。
  - 工数：実際に作業に投入される合計時間（例: 16人時）。
- **カレンダー（稼働日・非稼働日）制御**
  - 土日祝日や会社指定の休日を「非稼働日」として登録。
  - スケジュール計算時、非稼働日を自動的にスキップして終了日を決定する。
- **手動スケジュール / 自動スケジュール切り替え**
  - 自動：依存関係やカレンダーに基づいて日付をシステムが自動計算する。
  - 手動：ユーザーが指定した固定日付を優先する。

### 1-3. タスク依存関係（Predecessors / リンク）

タスク同士の接続条件と、変更時の自動リスケジュール（連動計算）ロジックです。

#### 依存関係タイプ（4種類）

1. **FS（Finish-to-Start / 終了-開始）**【最優先実装】
   - 先行タスクが終了したら、後続タスクが開始可能になる。
2. **SS（Start-to-Start / 開始-開始）**
   - 先行タスクが開始したら、後続タスクも開始可能になる。
3. **FF（Finish-to-Finish / 終了-終了）**
   - 先行タスクが終了したら、後続タスクも終了可能になる。
4. **SF（Start-to-Finish / 開始-終了）**
   - 先行タスクが開始したら、後続タスクが終了可能になる。

#### リード・ラグ時間

- **ラグ（Delay）**: タスク間にあける空き日数（例: FS + 2日 ＝ 終了後2日空けて開始）。
- **リード（Overlap）**: タスクの前倒し日数（例: FS - 1日 ＝ 終了1日前に開始）。

### 1-4. ガントチャート描画とクリティカルパス分析

スケジュールデータの視覚化と、プロジェクト遅延リスクの検知機能です。

#### 要件一覧

- **ガントチャート描画**
  - グリッド（表）とタイムライン（横棒グラフ）の同期表示。
  - タスク間の依存関係を矢印線（SVG等）で接続描画。
  - ズーム機能（日次 / 週次 / 月次 表示の切り替え）。
- **クリティカルパス（Critical Path）の算出とハイライト**
  - プロジェクト全体の完了日に直接影響を与える「余裕期間（トータルフロート）が0のタスク群」を判別。
  - クリティカルパス上のタスクバーやリンク線を赤色などの強調カラーで描画。

## 2. リソース・コスト管理（Resource & Cost Management）

### 2-1. リソース割り当て（Resource Assignment）

タスクを実行する「人・設備・資材」を定義し、タスクへ割り当てる機能です。

#### 要件一覧

- **リソースマスタ管理**
  - **作業リソース（Person/Machine）**: 要員（例: 山田太郎）や設備（例: サーバーA）。時間単位（時給・稼働率）で管理。
  - **材料リソース（Material）**: 消費される資材（例: ライセンス数、コンクリート等）。単位（個、個数等）で管理。
  - **コストリソース（Cost）**: タスクごとに発生する固定費用（例: 交通費、外部研修費）。
- **最大単位（Max Units / 稼働上限）の設定**
  - リソースごとの標準稼働率を設定（例: 100% = フルタイム稼働、50% = 半日稼働）。
- **タスクへの割り当てと割り当て率**
  - 1つのタスクに複数のリソースを割り当て可能とする。
  - 割り当て率（例: 担当者Aを50%の割り当てでアサイン）に応じた工数計算。

### 2-2. 負荷調整（リソース平準化 / Resource Leveling）

リソースの過剰割り当て（キャパシティオーバー）を検知・修正し、実現可能なスケジュールにする機能です。

#### 要件一覧

- **超過割り当て（山積みオーバー）の検知・警告**
  - 同一期間内にリソースの最大単位（例: 100%）を超える割り当てが発生した場合、警告表示（赤字ハイライト等）を行う。
- **リソースヒストグラム（山積み表）の表示**
  - 日次・週次ごとのリソース別負荷状況を棒グラフ等で視覚化。
- **手動 / 自動平準化（Leveling）**
  - **手動調整**: ドラッグ＆ドロップまたは日付変更でタスクをずらし、負荷を分散。
  - **自動調整**: システムが優先度や余裕時間（フロート）を計算し、超過割り当てが解消されるよう後続タスクを自動的に後ろ倒し（遅延）させる。

### 2-3. コスト管理（Cost Management）

リソースの単価とタスクの期間・工数に基づき、プロジェクト費用を自動計算・管理する機能です。

#### 要件一覧

- **単価（Rate）の設定**
  - 標準単価（例: 5,000円/時間）および超過勤務単価（例: 6,250円/時間）の設定。
  - 使用ごとのコスト（固定手当等）の設定。
- **コストの自動計算**
  - **算出式**: `タスクコスト = (割当リソースの作業時間 × 単価) + タスク固定コスト`
  - 親タスクおよびプロジェクト全体へコストを自動積み上げ（ロールアップ）集計。
- **コスト発生時期（計上タイミング）の制御**
  - **開始時（Start）**: タスク開始日に全額計上。
  - **日割り（Prorated）**: 期間に応じて毎日均等に計上（デフォルト）。
  - **終了時（End）**: タスク完了日に全額計上。

## 3. 進捗追跡・分析（Tracking & Reporting）

- **ベースライン設定**
  - 計画時点のスケジュール・コストの保存（実績との比較用）
- **進捗更新**
  - 進捗率（%）の入力
  - 実際にかかった工数（実工数）と残り工数の更新
- **レポート・ダッシュボード**
  - EVM（アーンド・バリュー・マネジメント）分析（SPI, CPIなどの指標算出）
  - 遅延タスク一覧、リソース稼働状況レポート
